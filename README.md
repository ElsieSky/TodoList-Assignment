# Backend CRUD Assignment — TS Academy

A RESTful backend API built for TS Academy to demonstrate full CRUD (Create, Read, Update, Delete) operations, route handling, and request processing.

---

## 🚀 Features

- **Create (POST):** Endpoint to handle new resource creation with payload validation.
- **Read (GET):** Endpoints to retrieve all records or fetch a single record by its ID.
- **Update (PUT / PATCH):** Endpoint to modify existing records.
- **Delete (DELETE):** Endpoint to remove records from the dataset.

---

## 🛠️ Tech Stack

- **Runtime:** Node.js
- **Framework:** Express.js
